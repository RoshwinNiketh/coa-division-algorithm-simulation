# Project Instructions

This is an educational Computer Organization and Architecture project.

The website teaches and simulates:
- Restoring Division
- Non-Restoring Division

Priority order:
1. Algorithmic correctness
2. Beginner-friendly explanation
3. Clear step-by-step simulation
4. Modular reusable architecture
5. Simple UI
6. Visual polish

Rules:
- Keep algorithm logic separate from React UI code.
- Generate a complete structured trace for every calculation.
- Explain every register update and arithmetic operation.
- Keep Restoring and Non-Restoring algorithms in separate modules.
- Make components reusable for a future larger COA simulator project.
- Do not add backend, authentication, database, or unrelated features.
- Add automated tests.
- Run tests and production build before completion.
